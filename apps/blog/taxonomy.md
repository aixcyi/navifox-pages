# 分类注记

　　文章按「领域 × 类型」两个维度分类：**领域**回答“讲什么”，**类型**回答“怎么写”。两轴相互独立，目录页支持按任一维度筛选。本文是这两个维度的写作词典，动笔前请对照选择。

## 领域

| 领域 | 边界定义                                   |
|----|----------------------------------------|
| 语言 | 编程语言本身的机制、语义与标准库。                      |
| 框架 | 框架与库的使用方式（Django、Vue 等）。               |
| 算法 | 算法与数据结构，目前以题目解答为主。                     |
| 前端 | 界面实现与浏览器行为（CSS、渲染、组件表现）。               |
| 工程 | 工程实践与工具链：构建、类型检查、依赖管理、业务对接。            |
| 系统 | 操作系统、桌面环境与部署环境（注册表、CentOS、virtualenv）。 |
| 安全 | 漏洞、CTF、恶意软件与安全事件分析。                    |
| 生活 | 记录叙事：个人经历、校园家庭、日常片段。                   |

## 类型

| 类型 | 边界定义              |
|----|-------------------|
| 教程 | 步骤清晰、可照做的“怎么做”。   |
| 笔记 | 零散但有用的事实与技巧记录。    |
| 复盘 | 对一次具体事件/踩坑的回顾与归因。 |
| 思考 | 对主题的独立思辨。         |
| 选型 | 方案对比与选择。          |

## 使用规则

- 每篇文章的领域与类型**各取其一**，分别对应 frontmatter 中的 `domain` 与 `genre` 字段；标签（`tags`）自由填写、数量不限。
- 领域按需增长：新主题先以标签积累，成体系后再升格为领域；目录页的领域筛选按钮由文章动态生成。
- 类型以“怎么写”为准：同一个主题既可以写成复盘，也可以写成教程，按行文方式选择。
- 尚未启用的领域（如安全、生活）已在本词典预先登记，待第一篇文章发布后即出现在目录中。
